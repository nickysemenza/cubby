Can shared records replace cache choreography?

Change one Task and watch its loaded list, detail, and Project relationship together. This file embeds the real Query Collection adapter. Its server is an in-memory simulation: it never contacts Cubby or stores household data.

Scope: one bounded server page, two Project records, and optimistic writes. This proves collection behavior, not a production migration. The separate on-demand loading probe requested an unbounded fallback and was rejected.
